# WebPageChecker

App iOS (SwiftUI) qui vérifie l'état HTTP d'une page web.

## Fonctionnement

1. Saisis l'URL de la page à vérifier.
2. Appuie sur **Rafraîchir**.
3. L'app affiche le code HTTP (ex. `200 OK`), le temps de réponse, et l'heure de la dernière vérification.

Pas de vérification en arrière-plan : le check se fait uniquement quand tu appuies sur le bouton.

## Ouvrir le projet

Ouvre `WebPageChecker.xcodeproj` avec Xcode (16.0+ recommandé) et lance sur le simulateur ou un appareil.
